**PD-6. add_box placement (B10).**
- **Patcher (patcher.py):**
  - `class BoxMovedWarning(UserWarning)`, next to EditResult, with a one-line docstring.
  - `Box.__init__` sets `self.nudged_from: tuple[float, float] | None = None`. Readers use `getattr(box, "nudged_from", None)`, because builder boxes come from `Box.__new__`.
  - A new method `_nudge_off_overlap(self, x, y, w, h) -> tuple[float, float, Box | None]`. It uses the same rect source as `_find_clear_position`: `rendered_rect(box, max_saved=is_max_saved(self.props))`, falling back to patching_rect. The steps:
