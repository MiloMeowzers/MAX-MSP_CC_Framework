## Deviations from Plan

**1. [Rule 2/3 - Save gate] Toggle initialized by loadbang -> `0` -> toggle**
- Found during: Task 1, pre-save check.
- Issue: a plain toggle that reaches sfrecord~ (through route) is a save-gate blocker ("Uninitialized state"), and `test_validates_and_reviews_clean` pins 0 blockers. A second loadmess would break the pinned `_one(p, "loadmess")`; parameter mode would mean guessing toggle parameter attributes.
- Fix: `loadbang` -> msg `0` -> toggle, the critic's suggested form; the toggle stays plain (parameter_enable 0, no presentation). test_kill_switch asserts this path.
- Layout consequence: two more rows above the toggle, so the shift is +160 instead of +80 (route at y 340, branch row 420, udpsend 645); patcher window height 450 -> 720 so the whole patch stays visible.
