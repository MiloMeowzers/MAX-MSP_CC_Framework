- D-02: An exception raised inside the with-body writes nothing (discard).

  - route touched cords only (the existing `_box_added_or_moved` / `_finalize_midpoints_recursive` logic in hooks.py);

  - no global auto-layout, no full finalize, no assistance-comment fill.
- D-04: A no-op session, where `format_patch_text(new, original_text) == original_text`, writes nothing and commits nothing. This keeps the Q29 byte-identical guarantee.
- D-05: Atomic writes for ALL writers: `_write_and_sync` goes through `atomic_io.atomic_write_bytes`, so save_patch_roundtrip, write_gendsp and write_js all change. Note this in SUMMARY. The session reuses `save_patch_roundtrip(..., original_text)` for the stale check, `_run_save_gate`, `format_patch_text`, the write and the path-scoped auto-commit, and duplicates none of them.
- D-06: Diff identity: boxes match by box id. "moved" means any patching_rect x/y change. A size change is reported separately. Changes to the `presentation` flag and to `presentation_rect` are reported as presentation changes.
- D-07: The diff recurses into embedded subpatchers and bpatcher embeds, path-prefixed (e.g. `p foo/obj-12`), with the same id matching at each level.
- D-08: `force=True` is passed through only when the user confirms (CLAUDE.md Rule #7). The session passes it to save_patch_roundtrip unchanged, and the docs say "only with user confirmation".

- Session shape:
  - `edit_patch(path, *, force=False)` returns an `EditSession`, and `__enter__` returns the Patcher. So `with edit_patch(path) as p:` works, and `s = edit_patch(path)`, `with s as p: ...` keeps the result.

- `__enter__`:
  - raises RuntimeError("edit session already active") when `_active`;
  - otherwise calls `_hooks.read_patch(self.path)`, which re-reads on every enter, so FileNotFoundError propagates;
  - sets `_baseline = json.loads(self.original_text)`, resets saved, commit_hash and diff, sets `_active = True`, and returns the Patcher.
- `__exit__(exc_type, exc, tb)`:
  - Always clear `_active` in a finally block, and always return False so exceptions propagate.
  - If `exc_type` is not None, return immediately: no routing, no serialization, no write (D-02). This covers BaseException subclasses such as KeyboardInterrupt.
  - Otherwise:
    1. call `_hooks._finalize_midpoints_recursive(self.patcher, layout._generate_midpoints)`, which routes touched cords only (D-03);
    2. set `new_dict = self.patcher.to_dict()`;
    3. set `self.diff = diff_patch_dicts(self._baseline, new_dict)`, BEFORE any save, so it survives a refusal (D-01);
    4. if `_hooks.format_patch_text(new_dict, self.original_text) == self.original_text`, return: no stale check, no gate, no write, no commit (D-04);
    5. otherwise set `self.commit_hash = _hooks.save_patch_roundtrip(new_dict, self.path, self.original_text, force=self.force)` and then `self.saved = True` (D-05, D-08). Do not catch StaleFileError, PatchValidationError or SaveGateWarning.
- `current_diff() -> PatchDiff`: the diff of `_baseline` against `self.patcher.to_dict()`. It raises RuntimeError when the session was never entered. It works inside the block and after exit.

`def edit_patch(path, *, force=False) -> EditSession`: the docstring shows `with edit_patch(path) as p:` and the `s = edit_patch(path)` form that keeps the result.
