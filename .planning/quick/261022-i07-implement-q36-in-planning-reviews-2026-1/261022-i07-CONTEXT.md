<decisions>
## Implementation Decisions

### Gate / stale refusal on exit
- Raise and write nothing: `PatchValidationError` / `StaleFileError` propagate out of the with-block; file untouched, nothing committed. The edited Patcher remains inspectable via the session/context object.
- An exception raised inside the with-block body also writes nothing (discard).

### Exit scope
- On exit: route touched cords only (added/moved boxes, the existing `_box_added_or_moved` / midpoint logic in hooks.py) + text-contrast repair scoped to TOUCHED boxes only (added, moved, or presentation-changed; private `only_ids` filter on `_apply_text_contrast`). Whole-patch `repair_text_contrast` is NOT run (it would change 33/63 committed patches on a no-op — user decision after research, supersedes earlier "repair_text_contrast(patcher)" answer). No global auto-layout, no full finalize.
- No-op session (format_patch_text(new) == original_text) writes nothing and commits nothing.

### Atomic writes
- Route `_write_and_sync` through `atomic_io.atomic_write_bytes` for ALL writers (save_patch_roundtrip, write_gendsp, write_js), not just edit_patch. Note it in SUMMARY.
- Then reuse `save_patch_roundtrip(..., original_text)` primitives (stale check, `_run_save_gate`, `format_patch_text`, atomic write, path-scoped auto-commit). Do not duplicate them.

### Diff identity
- Match boxes by box id. "moved" = any patching_rect x/y change (delta > 0); size change reported separately; `presentation` flag and `presentation_rect` changes reported as presentation changes.

### Recursion
- Diff recurses into embedded subpatchers / bpatcher embeds, path-prefixed (e.g. `p foo/obj-12 ...`), same id matching per level.

### Claude's Discretion
- Return value / session object shape (e.g. expose commit hash, diff, orphaned cords after exit).
- Diff data structure and text renderer format (keep compact).

</decisions>
