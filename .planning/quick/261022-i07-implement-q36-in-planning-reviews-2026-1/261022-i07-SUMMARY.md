## Atomic writes across all writers (D-05)

- `_write_and_sync` now writes through `atomic_io.atomic_write_bytes(Path(path).resolve(), content.encode("utf-8"))`. This makes **save_patch_roundtrip, write_gendsp and write_js all atomic**: temp file `.atomic-*.tmp` in the target's directory, fsync, then `os.replace`.
- An existing file keeps its mode; a new file gets the umask default.
- The file gets a **new inode**, so extended attributes on the old file (macOS xattrs) are dropped.
- **Symlinks are resolved**: the link stays a link and its target is replaced.
- POSIX bytes are identical to the old text-mode write.
- `import os` stays in hooks.py only because existing tests patch `src.maxpat.hooks.os.fsync`, which is the global `os.fsync`.
- **Residual TOCTOU**: MAX can still save between the stale check's read and `os.replace`. The window is narrowed, not closed (T-i07-01, accepted).

## Claude's-discretion choices

- **Session shape**: `edit_patch(path, *, force=False) -> EditSession`, and `__enter__` returns the Patcher. After exit the session exposes `saved`, `commit_hash`, `diff`, `patcher` and `original_text`; `current_diff()` previews the change mid-block. Orphaned cords show up as `cord_removed` entries; there is no separate list. Existing files only: a missing path raises FileNotFoundError.
- **Contrast scope: top level only**, matching `ensure_text_contrast` on new patches. A box counts as touched when it is added (its id is not in the baseline, or `_box_added_or_moved`), moved, or its presentation flag or rect changed.
- **Diff structure**: a flat list of frozen `DiffEntry` records. `path` holds ancestor ids; `where` is the rendered prefix. `attrs` new = sorted tuple of changed keys (every key except id, maxclass, text, numinlets, numoutlets, outlettype, patching_rect, presentation, presentation_rect, patcher). `text` compares the display label (the newobj text, or `maxclass text`). `cord_rerouted` compares first-occurrence midpoints, with empty or missing normalised to None.
- **Z-order line**: `z-order changed (N boxes)`, where N = len − LIS (the boxes that actually changed stacking place). `bring_to_front` reports 1.
- **Render**: `+ id [label] @x,y`, `- id [label]`, `~ id [label] moved a,b -> c,d`, `resized wxh -> wxh`, `~ id text "a" -> "b"`, `attrs k1,k2`, `presentation off -> on [x,y,w,h]`, `+/- id [label] subpatcher (N boxes)`, `+/- cord src:o -> dst:i`, `~ cord … rerouted`, `~ patcher props k`, `~ z-order changed (N boxes)`, then `... N more` after `max_lines` lines and a final summary line, `N change(s): 2 box_added, 1 cord_added`. An empty diff renders `no changes`.
