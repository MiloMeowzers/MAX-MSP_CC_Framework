<reference_data>
**Parser API (`src/maxpat/genexpr_parse.py`).** Pure functions, stdlib only (`re`, `dataclasses`). It imports nothing from `src.maxpat`, so codegen, rnbo and code_validation can import it at module top without a cycle. No function ever raises on any str input, and non-str input is treated as `""`.

- `DECL_TYPES` = ("Param", "History", "Delay", "Buffer", "Data"). `CONSTANTS` = frozenset of e, pi, twopi, halfpi, invpi, ln2, ln10, log10e, log2e, sqrt2, sqrt1_2, degtorad, radtodeg (case-sensitive).
- `mask(code) -> str`
  - The result has the same length as `code`. It is made in a single left-to-right scan with states normal, line comment, block comment and string.
  - Every character of a `//` or `/* */` comment becomes a space, except `\n` and `\r`, which are kept.
  - Only double-quoted strings count. Their contents become spaces; the quotes are kept, and a backslash escapes the next character.
  - An unterminated comment or string runs to EOF.
  - `//` inside a string, `"` inside a comment, and `/*` inside `//` are all inert.
- `Stmt` (frozen dataclass):
  - `start`, `end`: span in the ORIGINAL text; `end` is exclusive and includes the `;` or `{` that ended it;
  - `text`: the masked slice;
  - `depth`: brace depth at the start;
  - `line`: 1-based line of the first non-space character;
  - `kind`: one of "decl", "assign", "expr", "header";
  - `parents`: a tuple of the enclosing blocks' keywords, outermost first. The keyword is the header's first identifier when it is `for`, `if`, `else` or `while`, otherwise "func".
  - `terminated`: bool, True when the statement ended with `;`.
- `statements(code) -> list[Stmt]`. It works on the mask, tracking paren depth and brace depth.
  - A statement ends at `;` at paren depth 0. So a `for (i = 0; i < 4; i += 1)` header stays whole.
  - It also ends at `{`, which makes a "header" and pushes that header's keyword.
  - At `}`, any pending non-blank text becomes an unterminated statement, then the stack pops.
  - At EOF, pending non-blank text becomes an unterminated statement.
  - Whitespace-only segments are dropped. Depths never go below 0.
  - kind is set as follows:
    - "decl" when the stripped text starts with a DECL_TYPES word followed by whitespace;
    - "header" when the statement ended at `{`;
    - "assign" when there is an assignment operator at paren depth 0 (`=`, `+=`, `-=`, `*=`, `/=`, but not `==`, `<=`, `>=` or `!=`);
    - otherwise "expr".
- `split_args(s) -> list[str]`: splits on top-level commas, paren and bracket aware.
- `declarations(code) -> list[tuple[str, list[str], Stmt]]`: (type, names, stmt) for each "decl" statement at any depth. names holds every top-level comma item's leading identifier, so `History a(0), b(0);` gives both a and b.
- `parse_params(code) -> list[dict]`: one dict per Param name, with exactly the keys name, default, min and max.
  - default is `float()` of the first positional (non-`kw=`) argument, or None when it is absent or not a plain numeric literal (`-1`, `0.5`, `1e3`).
  - min and max come from `min = <literal>` / `max = <literal>` kwargs anywhere in the arguments, whitespace tolerated. They are None when absent or non-literal.
- `assigned_names(code) -> dict[str, list[int]]`: name → the 1-based lines of each assignment.
  - Sources: every non-decl statement at any depth, plus a `for` header's init and increment parts.
  - Before reading the LHS, strip a leading `else` and a leading `if`/`while`/`for` keyword with its balanced paren group.
  - The LHS is the text before the first depth-0 assignment operator. It may be a comma list (`a, b = peek(...)`). Only bare identifiers count.
  - Excluded: comparisons, `kw=` arguments at paren depth > 0, and declarations.
- `io_counts(code) -> tuple[int, int]`: `\bin(\d+)\b` / `\bout(\d+)\b` maxima on the mask.
- `line_paren_depths(code) -> list[tuple[int, int]]`: for each `code.split("\n")` line, the paren depth on the mask at the line's start and at its end, clamped at 0.

**Reorder algorithm (`reorder_genexpr_declarations`).**
- An "expression statement" is any non-decl statement, at any depth (headers included), whose masked text contains `=` or matches `\w+\.\w+\(`. That is the existing line rule applied per statement.
- If no depth-0 decl statement follows an expression statement, return `code` unchanged.
- Otherwise every depth-0 decl statement becomes a piece:
  - **Start.** The piece starts at the statement's span. If only whitespace (on the mask) precedes it on its line, it starts at the line start instead, extended up over the contiguous run of whole-line `//` comment lines directly above it. A blank line stops the run.
  - **End.** It ends at the span end, extended through the end of the line and its newline when the rest of the line is whitespace on the mask (that is, only a trailing comment).
- Remove the pieces from the original text. Drop any line that is left whitespace-only by a removal (a line whitespace-only in the original is kept).
- Emit the pieces grouped Param, then History, then Delay, then Buffer/Data (stable within each group), each ending in a newline. Then one blank line, then the remainder with its leading blank lines removed.
- Never slice the mask into the output.

**De-hoist fixpoint (Check 14).**
- P = Param names. S = History/Delay/Buffer/Data names. B = P ∪ {samplerate, vectorsize} ∪ CONSTANTS.
- For each assignment (as in `assigned_names`), take its RHS identifiers on the mask: `(?<![\w.$])[A-Za-z_]\w*`, excluding names directly followed by `(` (calls) and `kw` in `kw=` at paren depth > 0.
- D (derived locals) starts empty. Repeat until nothing changes: add a name n when all of these hold:
  - n has exactly one assignment, and it is a plain `=`;
  - n ∉ S ∪ P;
  - its RHS identifiers ⊆ B ∪ D. A literal-only RHS counts, so `RING = 1344000;` is derived.
- Flag each n ∈ D whose RHS identifiers include at least one name in D and at least one name in P.
- `srs = samplerate * one` with `History one(1);` is never derived, because `one` ∈ S. That is how the de-hoisted form passes.

**Check rules (new Checks 10-16).** All checks run on the mask except Check 10.
- **10 Tab.** `"\t"` in the RAW code. A tab inside a comment still counts (genexpr-rules.md). One result.
- **11 Constant assignment.** `assigned_names` ∩ CONSTANTS. One result per name, at the first line.
- **12 Param assigned.** Param names ∩ `assigned_names`. One result per name, at the first line.
- **13 Loop shape.** Applies to each `for` header.
  - **Nested:** "for" is in its `parents`. Report the enclosing `for`'s line: track the header lines.
  - **Non-literal bound:** split the header's paren content on top-level `;`. The middle (condition) part, with whitespace removed, must match identifier, a comparison operator (`<=`, `<`, `>=`, `>`, `!=`), then a numeric literal (optionally negative, optionally decimal), or the same reversed. Otherwise it is flagged. An empty condition is flagged.
