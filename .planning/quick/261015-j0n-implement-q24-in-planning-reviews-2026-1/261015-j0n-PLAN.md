**`control_walk` contract.** `PatchGraph.control_walk(scope, box_id, *, downstream: bool, max_depth: int = 64)` is a generator of `(Scope, box_id)` pairs in BFS order. Rules:
- The start is never yielded; each (scope, box id) is yielded at most once (visited set).
- Cords: downstream follows `scope.out_edges` stable-sorted by outlet; upstream follows `scope.in_edges` stable-sorted by inlet. A cord with `Edge.signal` True is never followed.
- Crossing: a cord into a crossing container (`_crossing_child`, contexts max/bpatcher) continues at the inner `inlet` box of that x-rank (downstream) or the inner `outlet` box of that rank (upstream). Reaching an inner `outlet` (downstream) or `inlet` (upstream) box of a crossing scope continues along the parent container's cords at that rank, still skipping signal cords. Crossing containers and port boxes are transparent: traversed, never yielded.
- Bridges (non-gen, non-rnbo scopes; channel = the literal first argument). Downstream: send/s X -> every receive/r X; value/v X -> every other value/v X; pv X -> every other pv X in the same, an ancestor or a descendant scope; a message box -> every receive/r T and value/v T for each `;` segment target T. Upstream mirrors this: receive/r X -> every send/s X and every message box with a `;` segment targeting X; value/v X -> other value/v X and message boxes targeting X; pv X -> related pv X.
- `;` targets: maxclass `message` with str text; split on `;` not preceded by a backslash; for every segment after the first, the first whitespace token (after stripping spaces, `\r`, `\n`) is a target (`;\rwhrt pitch 7` targets `whrt`).
- Depth: the start is depth 0; each cord hop or bridge hop adds 1 (crossing a port rides on the cord that caused it). A node at `max_depth` is yielded but not expanded.
- Read-only; malformed boxes, args, text, lines and ports never raise. The bridge map is built lazily once per graph and cached in a new `__slots__` entry.
