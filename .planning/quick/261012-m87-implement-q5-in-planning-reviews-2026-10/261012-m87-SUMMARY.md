## Deviations from Plan

None in behavior. Minor implementation notes:
- `auto_commit_patch` passes `-q` to `git commit`. Output is captured either way.
- `_auto_commit_saved_file` requires `patches/<project>/` among the file's *directory* parts. A file directly in `patches/` (for example `patches/.active-project.json`) counts as "outside patches/<project>/" and warns. The old code would have treated the file itself as the "project dir".
- The plan's final gate script uses unquoted `$H` word-splitting, which fails under zsh. I ran it under `bash -c` and it passed.

## Residuals (out of scope)

- **TOCTOU window:** the file could change between the stale check and the write. The window is milliseconds; Q36 owns atomic writes (threat T-m87-03, accepted).
- **Unchecked overwrites remain:** saves with `original_text=None`, plus `write_gendsp` and `write_js`, still overwrite without checking (Q29/Q36).
- **`index.lock` contention:** when concurrent instances collide on git's index lock, the save shows an "auto-commit failed" warning. There is no retry.
- **Paths outside `patches/<project>/`:** Ambire, MUSC320, TCI and SCI are still not auto-committed, but they now warn instead of skipping silently.
- **No-op saves now warn** ("no changes to commit").
