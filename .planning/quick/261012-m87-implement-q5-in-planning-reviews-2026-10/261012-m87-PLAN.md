## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Save functions -> git index on a shared `main` | Concurrent Claude instances stage and commit in the same repo. A patch save must commit only its own path. |
| MAX (user edits on disk) -> agent save | The file on disk can change between `read_patch` and `save_patch_roundtrip`. User work must not be silently overwritten. |
| Caller-supplied path, description and filenames -> git subprocess | The values become git argv elements and pathspecs. |
| Test suite -> developer's real repo | The new tests run real git and must never touch the MAX repo. |

| T-m87-01 | Tampering | `auto_commit_patch` whole-index commit (A5) sweeps another instance's staged files into a patch commit | high | mitigate | `git commit -m msg -- <abs paths>` from the rev-parse root, plus a pathspec-scoped `diff --cached --quiet`. Tests: pre-staged other.txt stays out of the commit and stays staged; a no-op save makes no commit. |
